# BarState 1.0.0

BarState 1.0.0 brings native macOS Settings, more ready-to-use data sources, and clearer daily monitoring.

## Highlights

- Native Settings sidebar with separate Connection & Parsing, Menu Bar, and Alerts sections, shared drafts, and a fixed save area.
- DeepSeek balance, OpenRouter key usage/budget, and SiliconFlow China balance presets; test a key and choose a metric without writing parsing rules.
- Prometheus templates for CPU, memory, disk, and target scrape status, with explicit target selection.
- Consistent freshness, previous-value, offline, and failure information across the app.
- Optional local threshold/failure alerts with incident deduplication, recovery notifications, and click-to-open monitor settings.
- No transient menu bar refresh icon, reducing flicker during slow or frequent requests.
- Fixes for stale requests overwriting edited settings and monitor ordering reverting after moves or saves.

## Downloads

Requires macOS 15 or later. English and Simplified Chinese are supported.

- Apple Silicon: **BarState-macos-arm64.dmg**
- Intel: **BarState-macos-x86_64.dmg**

Open the DMG and drag BarState into Applications. Homebrew users can run `brew update` followed by `brew upgrade --cask barstate`.

The app is ad hoc signed and is not Apple-notarized. Use the official release assets or Homebrew tap; see the installation guide for macOS security prompts.

## Validation notes

DeepSeek, the existing Codex primary quota window, packaged notification delivery, and notification click navigation were checked on a real account or system. OpenRouter / SiliconFlow real-account checks, actual re-login and sleep/network recovery, and VoiceOver navigation were explicitly deferred and remain unverified. Codex multi-window expansion is deferred; the existing primary-window behavior remains.
