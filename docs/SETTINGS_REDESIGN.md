# Settings 面板重构建议

本页为 [完整迭代计划](NEXT_ITERATION.md) 的 UI 详细资料，实施范围与顺序以主计划为准。

用户已确认原生 macOS 侧栏与任务分区，以及 Apple 表单样式、Raycast 信息密度、Proxyman 局部连接调试区域的组合。现按此方案实现，不估工期；完成程度见 [实施记录](ITERATION_PROGRESS.md)。实际界面参考见 [Settings 样式参考](SETTINGS_STYLE_REFERENCES.md)。

## 核心目标

让用户选中一个监控项后，能迅速找到要修改的设置，并看见修改结果。常见任务分为连接数据源、调整菜单栏显示、配置提醒；运行状态贯穿这些任务。使用模式为 Operate，以操作效率、可读性和原生桌面习惯为准。

## Direction contract

THESIS: 选中监控后按连接、显示、提醒完成任务；以已确认的原生分区替换长表单堆叠。

OWN-WORLD: macOS 语义背景、系统字体、细分隔和紧凑控件；浅深色跟随工作环境。Apple 表单、Raycast 密度、Proxyman 局部响应区域。

STORY: 选择来源，测试实际数值，预览菜单栏，按需提醒；错误紧邻可修正的字段。

FIRST VIEWPORT: 1120×760 窗口，约 220 点侧栏；右侧固定监控标题、任务分区与底部保存，表单独立滚动。

FORM: 用户已确认的 native macOS canon；依据三组实际参考和迭代计划直接实现，方向来源为用户选择，无随机种子。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 当前问题

| 问题 | 现有结构 | 改进方向 |
| --- | --- | --- |
| 左栏职责混杂 | 监控列表底部同时摆放语言、菜单栏模式、长度、登录启动，以及删除和排序按钮 | 左栏专注选择与管理监控；全局偏好收进“通用设置”入口 |
| 常用任务层级不清 | 名称、显示模板、颜色规则先于请求和解析，颜色规则展开后将连接操作向下推 | 把监控身份放到固定顶部，右侧内容按操作任务分区 |
| 页面宽却需要长距离滚动 | 普通输入框、辅助文案、颜色规则、完整响应和解析编辑器纵向堆叠 | 限制常规表单阅读宽度，响应/代码区域按需使用空间，减少无关内容同屏竞争 |
| 样式缺少主次 | 大标题、整行状态条、长分隔线、控件边框和深色响应区共同抢占注意力 | 用系统字体层级、分组间距和必要的分隔表达结构；调试内容降低默认视觉权重 |
| 操作反馈有距离 | 显示模板与预览、请求与解析结果被多个设置组拉开 | 将反馈紧邻对应输入或测试操作，保留底部保存反馈 |

## 已确认布局：原生侧栏与任务分区

| 区域 | 放置内容 | 交互原则 |
| --- | --- | --- |
| 左栏顶部 | “监控项”与新增入口 | 常驻且简洁；克隆、删除、移动保留在明确的操作菜单或右键菜单中 |
| 左栏主体 | 名称、简短来源、当前值/状态 | 当前选择醒目；保留拖动排序及辅助操作，长名称不挤掉状态 |
| 左栏底部 | “通用设置”入口 | 进入语言、菜单栏模式/长度、登录启动等应用级偏好 |
| 右侧固定顶部 | 当前监控名称、数据源、启用开关、简洁状态摘要 | 直接说明正在编辑哪个监控；最近成功、过期或错误信息可展开查看 |
| 右侧分区栏 | “连接与解析”“菜单栏显示”“提醒” | 同一监控共享一份草稿；切换分区不丢输入、不重复要求保存 |
| 右侧内容 | 当前任务的必要设置及反馈 | 内容独立滚动；标题、分区和保存入口不随长响应移出视野 |
| 右侧固定底部 | 未保存/测试要求/保存反馈、撤销更改、保存 | 保留现有验证规则，错误提示能定位到需要处理的分区和字段 |

“提醒”分区随提醒能力一起交付，提前重构时只展示已有能力，不放无法使用的空入口。

## 各分区的内容

**连接与解析**：首先放数据源、接口或查询、刷新周期及测试操作。认证、请求头和超时归为高级连接选项；已配置时显示简短摘要。HTTP 的请求测试、响应与解析保留在同一分区，按“请求 → 响应 → 提取数值”排列。响应默认提供状态、类型和测试结果摘要，完整 Body 与 HTTP 详情可展开；解析成功值仍内联在测试解析按钮旁，代码编辑空间保持充足。出错时自动露出相关错误，不要求用户先找到折叠区。

Prometheus 只展示查询及其结果，Codex 只展示对应额度连接信息与测试，不让用户面对无关的 JSONPath、JavaScript 或认证配置。

**菜单栏显示**：显示开关、模板、实际效果预览、颜色规则。预览放在模板旁或紧接其后，修改即可对照。颜色设置归为一个紧凑的规则组；帮助文字明确每个值是下限，避免让用户误以为颜色规则本身会发送通知。已保存监控的显示开关继续即时生效，并明确区别于需要保存的字段。

**提醒**：接入路线图中独立的提醒规则；包含启用、触发条件、适用时的阈值、恢复通知、权限状态和一句完整规则摘要。沿用统一运行状态与新鲜度判断。

## 样式方向

已确认保留 macOS 原生语言，具体布局和样式一起调整：

- 使用系统语义背景、侧栏材料、系统字体和控件；仅在响应与表达式中使用等宽字体。
- 顶部以选中监控名称作为视觉重点，通用的“监控设置”标题降低权重；状态摘要紧凑，异常时再展开。
- 常规字段采用一致的对齐和宽度规则，短数值控件按内容占宽；同组紧凑、组间清楚，避免每个字段都占据整屏宽度。
- 用少量分组背景、间距和系统分隔线建立层级；蓝色集中在选择态和主要操作，状态色保留明确语义。
- 响应预览按浅深色主题调整对比度，展开后具有足够阅读空间；保留复制、文本选择及完整详情能力。

侧栏与任务分区结构、三组参考的组合均已确定，见 [三组官方界面参考](SETTINGS_STYLE_REFERENCES.md)。新增 DataSource 预设通过“添加监控”的来源列表选择；供应商表单默认只显示必要的凭据、指标与刷新设置，自定义 HTTP / Prometheus 保留完整配置能力。接口资料见 [DataSource 预设与接口资料](DATASOURCE_PRESETS.md)。

## 验收重点

- 在默认 1120 × 760 和最小 860 × 620 窗口中，顶部、分区导航和保存区均可操作；普通表单无横向滚动，长响应允许在自身区域滚动。
- 用户能找到“修改接口”“调整菜单栏格式”“修改语言”的对应入口；只改显示时无需经过请求详情。
- 同一监控切换分区保留草稿和测试状态；切换其他监控、进入通用设置或关闭窗口时，未保存内容仍受保护。
- 保存被测试要求阻止时，能直接定位连接/解析分区；该分区中的无效字段有明确提示。展开/折叠不改变测试是否有效。
- 启用/显示开关的即时生效语义、取消/保存、克隆、排序、删除确认与恢复模式均保留。
- 覆盖 HTTP、Prometheus、Codex、新建项、空列表、已有成功响应、认证失败和只读恢复；验证中英文、浅深色、长名称及键盘/VoiceOver 操作。
