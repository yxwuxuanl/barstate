`iteration-*` images are real native windows captured on 2026-09-07 from the isolated `com.barstate.BarState.IterationPreview` bundle. They use in-memory sample values and dummy API keys. They show the Settings UI included in BarState 1.0.0.

Capture method: macOS CUA app-window screenshot. Default-size captures may be proportionally reduced by the capture provider. Screenshots are JPEG bytes returned by that provider; they are not rendered mockups. Native window materials follow the current macOS version. Pixel content was not retouched. Each image embeds this origin in its metadata.

Existing `barstate-*` images are historical repository assets retained from baseline `ff854c8`. The filename containing `mockup` denotes a mockup. These assets are not evidence for the current iteration. Exact original generation details are unavailable.
